# Banking & Fintech Architecture Portfolio (VitePress Docs)

Hệ thống tài liệu kiến trúc cho 2 Sub-Projects:
- Sub-Project A: Interbank Payment Gateway (ISO 20022, Saga Orchestrator, EOD Settlement)
- Sub-Project B: Core Banking System (Double-Entry Ledger, Concurrency Lock, Audit Trail)

## Hướng dẫn chạy nhanh:
```bash
# 1. Cài đặt dependencies
npm install

# 2. Khởi động server tài liệu cục bộ
npm run docs:dev

# 3. Build static site phục vụ deploy
npm run docs:build
```
